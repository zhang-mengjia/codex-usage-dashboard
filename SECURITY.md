# Security Policy

## Supported versions

Security fixes are provided for the latest release.

## Reporting a vulnerability

Please do not disclose vulnerabilities in public issues.

Use GitHub's **Report a vulnerability** action in the repository Security tab. If that is unavailable, email `apolloz.neuro@gmail.com` with the subject `Codex Usage Dashboard security report`.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Do not include real access tokens, refresh tokens, account IDs, or private conversation content. You should receive an acknowledgement within seven days.
